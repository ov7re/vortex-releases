# Vortex — versions

Ce dépôt ne contient que les installateurs Windows de Vortex (le code source est privé).

**Installer Vortex** : ouvrez [la dernière version](https://github.com/ov7re/vortex-releases/releases/latest),
téléchargez `Vortex-Setup-<version>.exe` et lancez-le. Prérequis : [Docker Desktop](https://www.docker.com/products/docker-desktop/).

**Mises à jour** : une fois installé, Vortex vérifie lui-même ce dépôt, télécharge les nouvelles versions et propose
de redémarrer pour les installer. Il n'y a rien d'autre à faire.

Les versions sont publiées automatiquement par le workflow « Installateur Windows » du dépôt privé.
